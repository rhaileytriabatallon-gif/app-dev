# My favorite Anime: Attack on titan

## About 
**Attack on Titan (Shingeki no Kyojin) is set in a world where humanity lives inside massive walled cities to protect themselves from Titans—towering, humanlike beings that threaten human survival. The story begins with the fall of one of these walls, which forces the characters into a long, brutal conflict that gradually reveals the true nature of the Titans and the world beyond the walls.
